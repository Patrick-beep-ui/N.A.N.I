# Roadmap

## Base actual

- [x] Un proyecto Next.js con una configuración de entorno en la raíz.
- [x] Prisma y contexto personal en Supabase, sin cambiar los datos existentes.
- [x] Selección de memorias por proyecto, dispositivo y vigencia.
- [x] Chat mediante OpenCode y consulta/registro operativo mediante Engram.
- [x] Acceso por loopback, validación de origen, permisos y cancelación.
- [x] Pruebas de integración HTTP con servidores locales de prueba.

## Siguiente entrega

1. Validar el recorrido con las versiones reales de OpenCode y Engram instaladas en la PC del usuario.
2. Incorporar extracción y actualización de aprendizaje personal en Supabase, con evidencia y corrección del usuario.
3. Añadir transmisión de tokens si mejora la experiencia.

Voz, conectores personales y varios dispositivos se incorporan cuando exista una necesidad real. Un worker o una cola se agregan solo cuando se requiera ejecutar tareas fuera del ciclo actual de la aplicación.
